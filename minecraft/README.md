# Ayn Dual Screen — Minecraft

A second screen for Minecraft: Java Edition, for the AYN Thor. Same idea as the Stardew and Terraria
mods, same protocol, its own separate project.

The mod runs a small web server inside your game. Point a browser on your handheld at it and you get
your inventory, vitals, effects, a live terrain map and your position on the lower screen, without
taking any of it off the main one.

## A note on mods.toml

MinecraftForge and NeoForge spell dependency blocks differently. Forge wants:

```toml
[[dependencies.ayndualscreen]]
    modId = "forge"
    mandatory = true
```

NeoForge wants `type = "required"` instead. Give Forge the NeoForge spelling and it rejects the entire
file with `Missing required field mandatory in dependency` and refuses to load the mod — which surfaces
as "not a valid mod file" with nothing pointing at the real cause. Worth remembering if this is ever
ported.

## Requirements

- Minecraft: Java Edition **1.21.1**
- **MinecraftForge 52.x** for 1.21.1
- Java 21 (Forge for 1.21.1 requires it anyway)

Client-side only. There is nothing to install on a server, and it works in single-player, on a LAN
world, or on any server you connect to — it only reads what your own client already knows.

## Installing

Drop `ayndualscreen-<version>.jar` into your instance's `mods` folder and start the game.

That folder is **not** `.minecraft\mods` if you use a third-party launcher. PrismLauncher, MultiMC and
CurseForge each give an instance its own game directory, and the vanilla one is ignored entirely:

```
PrismLauncher\instances\<instance>\minecraft\mods\
```

The mod prints the address to use in the log the moment it starts:

```
[Ayn Dual Screen] Second screen is up on port 27302.
[Ayn Dual Screen] On your handheld, open:  http://192.168.1.20:27302/
```

Use **that** address on the handheld. `localhost` means the device you type it on, so on a handheld it
points at itself and fails — which is the single most common way this doesn't work.

## Port

Defaults to **27302**, not the 27301 the other two mods use. Minecraft and Terraria are both likely to
be installed on the same PC, and two mods fighting over one port fails in a way that looks like the
app's fault rather than a collision.

## Config

`config/ayndualscreen-client.toml`, created on first run.

| Setting | Default | What it does |
| --- | --- | --- |
| `port` | 27302 | Where to listen. |
| `allowLanAccess` | **true** | Answer other devices, not just this PC. Off binds loopback only. |
| `showHostiles` / `showPassives` / `showPlayers` | true | What gets a dot on the map. |
| `maxEntities` | 80 | Cap on markers. Nearest kept. |
| `entityRange` | 64 | How far out to look, in blocks. |
| `mapRadius` | 64 | Half-width of the terrain map. Cost grows with the square of this. |
| `mapIntervalTicks` | 20 | How often the terrain map is rebuilt. |
| `allowHotbarSelect` | true | Tap the hotbar to change the held item. |
| `allowChat` | **false** | Let the second screen send chat and commands as you. |
| `allowDrop` | false | Let it drop the held item. |

The three under `control` are the only things the second screen can *do* as opposed to show, and the
two that can lose you something are off until you turn them on.

## How it works

The same shape as the other two mods, and for the same reason:

- The **client thread** builds a finished JSON snapshot every few ticks and publishes it to a `volatile`
  field. It is the only thread that ever touches the game.
- The **HTTP server** answers on worker threads and only ever hands out strings that were already
  finished. It never reads the game.
- **Commands** from the page go into a `ConcurrentLinkedQueue` and are drained on the next client tick.

Get that wrong and you get crashes that only happen on someone else's machine, so it is worth the
extra indirection.

The terrain map is generated by sampling the surface block at every column around the player and
painting its vanilla map colour, then encoding the result as a PNG. Unloaded chunks are left
transparent rather than guessed at, so the edge of what you have actually explored is visible.

## Building

```bash
cd AynDualScreen
gradlew build
```

The jar lands in `AynDualScreen\build\libs\`. The first build downloads and decompiles Minecraft and
takes several minutes; later ones take seconds.

## Assets

No game assets are copied or redistributed. The map is drawn from block colours in your own loaded
world at runtime, and the page uses text and CSS only — there are no item textures in the jar. See
`LICENSE.txt`.
